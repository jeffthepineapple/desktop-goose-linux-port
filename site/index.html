    Looks you save stay in this browser and ship together in one file.

    Put it on your goose

    1. Copy the command. It adds your look to skins.ini, so looks you already have stay put.
    2. Paste it in a terminal while the goose is running.
    3. The goose reloads its skins and puts the look on. Run it again after any change.

    Run CppGoose status to see ids. The first goose is 0.

    Needs CppGoose built from the latest main, which adds custom colors and skins reload.

    
        
    
        
    Saving this file as ~/.config/desktop-goose/skins.ini replaces any looks already in it. Use the terminal command to add instead.
